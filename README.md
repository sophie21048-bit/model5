# Доступный маршрут

Сайт строит пешеходный маршрут (Яндекс Карты), показывает на карте препятствия
и считает примерную оценку доступности в процентах.

## Файлы
- index.html, styles.css — страница и стили
- script.js — карта, маршрут, оценка в %, метки препятствий, база препятствий
- curb-model.js — блок «Сообщить о препятствии» (фото, координаты, проверка моделью Roboflow)
- obstacles.json — общая база препятствий (пока пустая, список [])

## Как работает оценка
Оценка = 100% минус штрафы за препятствия не дальше 25 м от линии маршрута.
Штрафы зависят от типа (лестница 20, сломанный бордюр 15, высокий бордюр 12,
препятствие 10, разбитое покрытие 8) и категории пользователя
(коляска x1,5, родитель с коляской x1,25, пожилой x1,1).
Если у пользователя включено «Избегать лестниц», штраф за лестницу ещё x1,5.
Если рядом с маршрутом нет данных, вместо процента показывается «нет данных».

## Куда вставить данные модели Roboflow (curb-model.js, самое начало)
- MODEL_ID: ID модели (Models -> кнопка копирования рядом с Model URL)
- MODEL_ID_ALT: запасной вариант, например "curbs-qavhj/4"
- API_KEY: Publishable Key (Roboflow: Settings -> API Keys)
Значения в прямых кавычках, без пробелов. Проверка моделью необязательна:
препятствия можно добавлять и без неё.

## Как делиться базой препятствий со всеми
Новые препятствия сначала сохраняются только в браузере того, кто их добавил.
Чтобы их увидели все посетители сайта:
1. Нажмите «Скачать JSON» в блоке «Сообщить о препятствии».
2. На GitHub откройте obstacles.json -> карандаш -> вставьте содержимое скачанного файла -> Commit changes.

## Как выложить на GitHub
1. github.com -> «+» -> New repository, Public.
2. Add file -> Upload files, загрузите все файлы с точными именами (без (1) и (5)).
3. Commit changes.
4. Settings -> Pages -> Deploy from a branch -> main, папка / (root) -> Save.
5. Сайт откроется по адресу https://ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/
